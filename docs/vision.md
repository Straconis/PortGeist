# Vision and use cases

PortGeist is a portable, general-purpose AI computer operator that works externally rather than requiring software installed on the target. The user supplies a goal, and the agent plans and executes a series of screen-based interactions, seeking help when needed.

## Example tasks

- Investigate a computer that cannot boot into its operating system.
- Navigate BIOS/UEFI and recovery environments where remote desktop tools cannot run.
- Perform routine setup, configuration, diagnostics, or software workflows.
- Operate a disconnected or isolated computer under explicit owner authorization.

## Non-goals for the concept phase

- No implementation, hardware purchase, or claim of reliable autonomy.
- No guarantee that every computer exposes usable HDMI or USB input at all stages.
- No bypass of access controls, passwords, encryption, or owner authorization.
